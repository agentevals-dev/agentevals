# agentevals Go API client

Generated Go types and gRPC clients for the `agentevals.api.v1alpha1` API.

The code is generated from `proto/` by `make proto-generate` and must not be edited by hand.
Releases are tagged `gen/go/vX.Y.Z`, matching the agentevals version.
